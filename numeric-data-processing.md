# Stream-Based Numeric Data Processing Engine

A C programming project that processes numerical data as it arrives
and calculates useful statistics in real time.

## 📖 About the Project

The Stream-Based Numeric Data Processing Engine is designed to receive
numerical values continuously and process them without requiring all
data to be stored before calculations are performed.

The program analyzes the incoming data and provides statistics such as
the number of values, sum, average, minimum, and maximum.

This project was developed to practice C programming concepts,
including loops, functions, arrays, pointers, and data processing.

## ✨ Features

- Read numerical data continuously
- Calculate the number of values
- Calculate the total sum
- Calculate the average
- Find the minimum value
- Find the maximum value
- Display processed results
